# Сайт цикла

Основная страница: `index.html`. Переводы всех видимых текстов: `translations.js`.
Оформление: `styles.css`. Поведение меню, темы и анимаций: `script.js`.

После изменения текстов или структуры выполните `node tools/build-site.mjs`.
Команда обновляет русскую страницу, казахскую и английскую версии в папках
`kk` и `en`, а также `sitemap.xml`. Редактировать языковые копии отдельно не нужно.

Для локального просмотра: `node tools/preview.mjs`, затем http://127.0.0.1:4173.
Сайт можно открыть и напрямую из файла: переключатель языков работает без сервера.

На хостинг нужны `index.html`, `styles.css`, `script.js`, `translations.js`,
папки `assets`, `kk`, `en`, `data`, `functions`, `lib`, файлы `_routes.json`, `robots.txt`,
`sitemap.xml` и файл проверки Google.
Cloudflare Pages: Framework preset None, Build command `node tools/build-site.mjs`,
Build output directory `.`. При пустой команде сборки можно публиковать готовые файлы.

Фотографии в PNG сохранены как оригиналы. Сайт загружает маленькие WebP-копии.

## Строка новостей

Строка получает до шести последних публикаций официального сайта Акорды:
https://www.akorda.kz/ru/events. Каждый заголовок сопровождается датой и ссылкой
на оригинал. Используются официальные русская, казахская и английская версии,
без автоматического перевода или изменения смысла. Это последние события,
не только поручения Президента.

Cloudflare Pages Function `functions/api/news.js` получает публичную страницу,
а `lib/akorda-news.mjs` извлекает только заголовки, даты и ссылки.
Новости кешируются на 30 минут, обновление происходит по запросу посетителя.
Постоянный фоновый сбор не нужен. Если источник временно недоступен, сохраненная
копия в кеше сервера может использоваться до суток с исходными датами.
Дополнительно публикуются резервные копии `data/news/ru.json`, `kk.json`, `en.json`:
они позволяют показать реальные заголовки даже при недоступности источника с Cloudflare.
Такая лента отмечена «Сохранённые», а копия старше семи дней — «Архив»; дата получения
сохранена и доступна в подсказке метки. Архив не выдается за свежие новости.
Если обе копии недоступны, показывается сообщение об ошибке и ссылка на источник.
Остальной сайт продолжает работать.
Бегущую строку можно остановить; при уменьшении анимации в настройках устройства
новости отображаются неподвижно с горизонтальной прокруткой.

Перед публикацией можно обновить резервную копию: `node tools/update-news.mjs`.
Команде нужен интернет; она получает реальные заголовки на трех языках и не заменяет
копии, если получение хотя бы одного языка завершилось ошибкой. Сборка страницы
`node tools/build-site.mjs` не требует интернета. Резервная копия сама по себе не
обновляется: свежие данные по-прежнему получает `/api/news` при успешном доступе
с Cloudflare. При отказе обработчик возвращает безопасный код причины (`code`),
HTTP-статус источника при наличии (`upstreamStatus`) и записывает их в журнал функции.
Нельзя считать автоматическое обновление на хостинге проверенным только по локальной версии.

Публиковать нужно через подключенный GitHub-репозиторий, вместе с `functions`,
`lib` и `_routes.json`. Загрузка только трех основных файлов не подключит ленту.
Ручной Direct Upload в панели Cloudflare не поддерживает Pages Functions.
Локальный сервер `node tools/preview.mjs` также обслуживает `/api/news`;
ему нужен доступ в интернет. При открытии `index.html` через `file://` автоматическая
лента недоступна, остается ссылка на Акорду.

Источник МО РК пока не добавлен: GOV.KZ отклонил прямой запрос `notAllowed`.
Обход ограничений и сторонние прокси не применяются. Если верстка Акорды изменится,
может потребоваться обновить обработчик. Для проверки: `node tools/test-news.mjs`.
Проверка резервной ленты при отказе источника: PowerShell `$env:NEWS_OFFLINE='1';
$env:PORT='4174'; node tools/preview.mjs`, затем http://127.0.0.1:4174.
