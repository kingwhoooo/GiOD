# Сайт цикла

Основная страница: `index.html`. Переводы всех видимых текстов: `translations.js`.
Оформление: `styles.css`. Поведение меню, темы и анимаций: `script.js`.

После изменения текстов или структуры выполните `node tools/build-site.mjs`.
Команда обновляет русскую страницу, казахскую и английскую версии в папках
`kk` и `en`, а также `sitemap.xml`. Редактировать языковые копии отдельно не нужно.

Для локального просмотра: `node tools/preview.mjs`, затем http://127.0.0.1:4173.
Сайт можно открыть и напрямую из файла: переключатель языков работает без сервера.

На хостинг нужны `index.html`, `styles.css`, `script.js`, `translations.js`,
папки `assets`, `kk`, `en`, файлы `robots.txt`, `sitemap.xml` и файл проверки Google.
Cloudflare Pages: Framework preset None, Build command `node tools/build-site.mjs`,
Build output directory `.`. При пустой команде сборки можно публиковать готовые файлы.

Фотографии в PNG сохранены как оригиналы. Сайт загружает маленькие WebP-копии.

## Строка новостей

Сейчас строка содержит ссылку на официальный раздел новостей МО РК на GOV.KZ.
Это не автоматическая лента заголовков. Прямое обращение к службе GOV.KZ
при проверке получило отказ `notAllowed`. Обход ограничений не применяется.
Для автоматического обновления нужен разрешенный RSS/API или согласованный
поставщик новостей. После подключения источник должен отдавать только заголовок,
дату и ссылку, без копирования полных публикаций; недоступность источника
не должна мешать работе сайта. Сторонние скрипты сейчас не подключены.
